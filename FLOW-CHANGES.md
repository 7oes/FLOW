# FLOW customization

- Black/purple default Dark theme and Segoe UI typography.
- FLOW window/console title, startup banner, wordmark and purple F icon.
- Arabic default interface with a live English/Arabic switch. Localized text direction changes independently of tab/workflow identifiers.
- Translation resources for static interface labels, tweak names and repair actions. Lazy tab contents receive the same resource bindings.
- A local build and launch entry point; UTF-8 BOM for Windows PowerShell 5.1 Arabic compatibility.
- Removed the in-memory elevation fallback that downloaded upstream WinUtil. Launch the local customized file when elevation is required.
- Original actions, package lists, logging and MIT attribution retained.

Source baseline: GitHub ChrisTitusTech/winutil main archive downloaded 2026-10-10. Archive snapshot is kept in the workspace; no commit identity was inferred from archive timestamps.
